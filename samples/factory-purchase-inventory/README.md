# 구매·재고 관리 화면 샘플

엑셀 기반 구매·재고 관리 시스템을 실제로 개발하기 전에 화면 흐름과 기능을 검토하기 위한 독립형 HTML 목업입니다.

## 실행 방법

`index.html`을 Chrome 또는 Edge에서 열면 됩니다. 별도 설치나 서버 실행은 필요하지 않습니다.

## 포함된 화면

- 오늘 업무 및 우선순위 작업 큐
- 발주 관리
- 재고 현황과 추천 발주량
- 생산 예약
- 자재·거래처 기준정보
- 자동화 규칙

버튼과 필터 등 주요 상호작용은 화면 검토용으로 동작하지만, 변경 내용은 브라우저를 새로고침하면 초기화됩니다. 실제 Google Sheets나 운영 데이터에는 연결되어 있지 않습니다.
