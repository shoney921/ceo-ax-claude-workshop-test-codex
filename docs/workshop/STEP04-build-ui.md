# STEP 04 · 내 화면(UI) 만들기

Hello, World!뿐인 화면을 **내 서비스의 화면**으로 바꿉니다.
재료는 "**내 시트의 실제 데이터 구조**"와 "사전 과제로 그려 본 **스케치 화면(HTML)**" 두 가지입니다.

아직 데이터를 연결하지는 않습니다. 이 단계의 목표는 **화면의 생김새**입니다.
(표·입력칸이 비어 있어도 괜찮습니다. 데이터는 STEP 06에서 연결합니다.)

---

## 1단계 : Claude Code가 내 시트 읽기

화면을 만들기 전에, Claude Code가 내 데이터의 실제 생김새를 알아야 합니다.
STEP 02에서 연결해 둔 **Google Drive 커넥터** 덕분에 직접 읽을 수 있습니다.

아래를 붙여넣습니다. `<시트 파일 이름>`은 Drive에 올린 스프레드시트의 이름입니다.

```
내 Google Drive에서 "<시트 파일 이름>" 스프레드시트를 찾아서 읽어줘.

읽은 다음 알려줘:
1. 탭(시트)이 몇 개고 이름이 무엇무엇인지
2. 각 탭의 열 이름이 무엇무엇인지
3. 각 탭이 전체 몇 행인지
4. 각 열에 어떤 값들이 들어 있는지 (예시 2~3개씩)

앞으로 이 프로젝트에서 데이터 구조가 필요할 때는
항상 이 원본 시트를 다시 읽어서 확인해줘. 구조를 파일로 따로 저장해 두지 마 —
시트는 계속 바뀌니까 원본이 항상 기준이야.
```

**여기가 처음으로 "연동"을 보는 순간입니다.**
브라우저로 올린 시트를, 지금 내 PC의 Claude가 읽었습니다. 두 세계가 연결된 겁니다.

> [!NOTE]
> **"파일을 찾을 수 없다"고 하면** : 시트 파일 이름을 Drive에 보이는 그대로 정확히 알려주세요.
> 그래도 못 찾으면 시트 주소(URL) 전체를 복사해서 "이 주소의 시트를 읽어줘"라고 하세요.
> 
> **"Drive에 접근할 수 없다"고 하면** : [STEP 02 문서의 3단계](STEP02-sheets-upload.md)(커넥터 연결)가
> 안 된 상태입니다. 연결하고 Claude Desktop을 재시작한 뒤 다시 시도하세요.
> 
> **여기서 막히면 손을 드세요.** 1단계가 확인되어야 이후 작업들이 가능합니다.

## 2단계 : 스케치 넣기

사전 과제로 만든 화면 스케치 HTML 파일을 `docs/reference/` 폴더에 복사합니다.
(파일 탐색기로 복사해도 되고, Claude Code에게 "이 파일을 docs/reference/에 넣어줘"라고 해도 됩니다)

## 3단계 : 화면 만들기

```
docs/reference/ 에 넣은 HTML은 사전 과제로 그려 본 예시 화면(UI)이야.
완성본이 아니라 참고용 스케치야.

방금 읽은 내 시트의 실제 데이터 구조와 이 스케치를 함께 참고해서
index.html 화면을 만들어줘.

- 기준은 실제 시트 데이터야. 스케치를 무조건 그대로 따르지 마.
- 스케치에는 있는데 시트 데이터로는 만들 수 없는 기능이 있으면,
  그대로 만들지 말고 나에게 "이건 데이터가 없는데 어떻게 할까?"라고 물어봐.
- 스케치보다 더 나은 표현이 있으면 제안해줘.
- 데이터 연결은 아직 하지 마. 표와 입력칸은 자리만 만들어 둬.

다 만들면 무엇을 왜 그렇게 만들었는지 두 문장으로 설명해줘.
```

## 4단계 : 내 PC에서 바로 확인하기

만든 화면은 **내 PC에서** 열어 봅니다. Claude Code에 이렇게 말하면 기본 브라우저로 열립니다 :

```
방금 만든 index.html을 브라우저로 열어줘.
```

작업 폴더에서 `index.html` 파일을 더블클릭해도 똑같습니다.
이제부터는 **고치고 → 브라우저 새로고침(`F5`)** 만 반복하면 됩니다.
마음에 안 드는 부분은 아래와 같은 말(프롬프트)로 수정을 요청하면 됩니다 :

```
제목을 더 크게 해줘. 표는 화면 아래쪽으로 옮기고, 입력칸을 위로 올려줘.
```

> [!NOTE]
> 이 단계에서는 **배포하지 않습니다.**
> 아직 시트에 연결하지 않은 화면이라, 내 PC에서 연 모습과 배포한 모습이 똑같습니다.
> 반면 배포를 하면 화면에 반영되기까지 1~2분을 기다려야 해서, 생김새를 고치는 동안에는
> 내 PC에서 보는 편이 훨씬 빠릅니다.
> 배포는 시트를 연결하는 [STEP 06](STEP06-connect-sheets.md)에서 다시 합니다.
> **시트 연결만은 배포된 주소에서만 동작**하기 때문입니다.

## 5단계 : 작업 저장하기

화면이 마음에 들면 지금까지 만든 것을 GitHub에 저장해 둡니다.

```
저장해줘
```

---

## ✅ 체크포인트

- [ ] 내 시트의 탭·열 이름들이 Claude Code 대화창에 떴다
- [ ] 브라우저로 연 `index.html`이 Hello, World!가 아니라 **내 서비스 화면**이 됐다
- [ ] 화면의 표·입력칸이 내 시트의 실제 열과 맞는다
- [ ] "저장해줘"로 지금까지의 작업을 저장했다
